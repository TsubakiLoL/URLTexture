A Godot plugin that loads URL images as Texture2D resources with intelligent caching and automatic updates.

## Features

- **URL to Texture2D**: Load images from URLs directly as Texture2D resources
- **Automatic Updates**: Downloaded images automatically refresh without replacing UI control textures
- **URL-based Caching**: Intelligent caching system based on image URLs
- **Resource Integration**: Seamlessly integrates with Godot's resource system

## Installation

1. Download the plugin files
2. Copy to your project's `addons/` directory
3. Enable the plugin in Project Settings > Plugins
